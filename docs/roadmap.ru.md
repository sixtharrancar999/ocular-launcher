# Ocular Launcher — планы

Три пункта, без расширения scope. Microsoft OAuth не планируется: лаунчер всегда играет под
оффлайн-ником. Это и есть идея проекта, а не то, что когда-нибудь исправят.

## [x] 1. Обновление игры и лаунчера

**Игра — готово.**

- При старте (и при каждом обновлении списка) лаунчер сравнивает установленную версию с последним
  релизом `horizon-rust/horizon`; список кешируется на 10 минут.
- Если вышла новая версия, на Play появляется баннер «Доступно обновление» с кнопкой.
- Обновление скачивает новый релиз (если нужно), переносит уже подготовленные ресурсы из любой
  подходящей версии (hardlink, `adopt_resources`) и выбирает новую версию.
- Если подготовленной версии нет вовсе — обычная подготовка.
- Откат: старая версия остаётся установленной, её можно выбрать на странице «Версии».

**Лаунчер — готово.**

- Проверка `https://github.com/sixtharrancar999/ocular-launcher/releases/latest/download/latest.json`
  при старте и по кнопке в настройках.
- Баннер на Play и раздел «Обновления» в настройках; скачивание с прогрессом, проверка
  minisign-подписи, перезапуск.
- Выпуск: тег `vX.Y.Z` → GitHub Actions собирает NSIS-установщик, подписывает его и публикует релиз
  с `latest.json`.
- Приватный ключ подписи хранится вне репозитория и в GitHub Secrets (`TAURI_SIGNING_PRIVATE_KEY`).

## [x] 2. Локальные скины

- Скин и плащ — PNG-файлы на этом ПК в
  `%LOCALAPPDATA%\Ocular Launcher\game\skins\<никнейм>\` (`skin.png`, `cape.png`, `model`);
  из сети ничего не скачивается.
- Настройки → «Внешность»: фигура из текстуры, загрузка скина (диалог или перетаскивание), выбор
  classic/slim, загрузка и удаление плаща, «Перезапустите игру, чтобы применить».
- Проверка формата: PNG 64×64 или 64×32 (скин), 64×32 / 22×17 / 46×22 (плащ).
- При запуске лаунчер передаёт `HORIZON_OFFLINE_SKIN`, `HORIZON_OFFLINE_SKIN_MODEL` и
  `HORIZON_OFFLINE_CAPE`.
- **Пока клиент 0.2.93 не читает эти переменные**, лаунчер записывает скин в подготовленные
  дефолтные текстуры игрока (`assets/minecraft/textures/entity/player/{wide,slim}`), сохраняя
  оригиналы в `.ocular-skin-backup` для отката. Никакого ресурспака — значит игра не пересобирает
  кэш на 28 000 файлов и не показывает долгий чёрный экран при первом запуске.
  Побочный эффект: другие игроки с дефолтным скином выглядят так же.
- В 0.2.93 модель рук (classic/slim) выбирает сам клиент; переключатель меняет превью и заработает
  в игре, когда Horizon начнёт читать `HORIZON_OFFLINE_SKIN_MODEL`.
- Внешность привязана к нику: сменили имя — своя внешность; вернули — скин на месте.

## [ ] 3. Инстансы

- Инстанс — своя папка `HORIZON_HOME` со своими мирами, `options.txt`, скриншотами и настройками
  запуска.
- Создание пустого инстанса, копирование существующего (без логов и кешей), переименование,
  удаление в корзину.
- Выбор инстанса на Play; последний выбор запоминается.
- У каждого инстанса свой ник и скин (через систему скинов).
- Инстансы не трогают основной `game/`: он остаётся первым инстансом.

## Вне scope

Microsoft OAuth и онлайн-аккаунты, моды и модпаки, хостинг серверов, сборки для macOS/Linux,
телеметрия.
